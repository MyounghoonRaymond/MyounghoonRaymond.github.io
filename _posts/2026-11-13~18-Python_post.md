26. 파이썬에서 코드를 작성하고 실행할 때 가장 많이 쓰이는 관용구

    1. ex) if __name __== "__main __":
    2. 파이썬은 파일을 실행할 때 내부적으로 현재 실행 중인 파일의 이름(__name __)을 확인
    3. 이 파일을 실행하면, 파이썬은 파일의 이름을 __main__이라는 특별한 이름으로 바꿔줍니다. 즉, 이 파일이 지금 프로그램의 메인 진입점이라는 뜻이 됩니다.
    4. 반대로 이 파일이 아니라 다른 파일에서 이 코드를 import 해서 쓸 때는 __name__자리에 이 파일의 실제 이름이 들어가기 때문에 __main__과 같지 않게 됩니다.
    5. Q: 왜 if문에 넣어서 쓸까? A: 나중에 이 코드를 다른 파일에서 재사용하거나 모듈로 불러올 때, 이 파일을 직접 실행했을 때만 이 테스트 코드가 동작하고, 다른 곳에서 쓸 때는 if ___name_ __ == " __main __": 이 아래 코드가 자동으로 실행되지 않게 막아주는 안전장치 역할을 합니다.
    6. ___name_ __ == " __main __" 에서 좌변의 __name __과 우변의 문자열 __main __은 사용자가 지정하는 파일 이름과 아무런 상관이 없는, 파이썬이 내부적으로 정해놓은 고유의 약속입니다.
    7. 좌변의 __name __ 는 파이썬이 모든 파일에 몰래 넣어두는 시스템 변수입니다. 이 변수에는 현재 파일의 이름이 자동으로 들어갑니다.
    8. 우변의 문자열 __main __ 는 파이썬이 지금 직접 실행되고 있는 메인 파일이라는 걸 표시하기 위해 붙이는 고정된 문자열 이름입니다.
27. try:  except: 문에서는 try: 에는 에러 발생이 예상되는 코드, except: 에는 에러 대응 처리 코드를 넣습니다.

    1. 예외 처리를 해놓으면 에러가 발생했을 때 프로그램이 비정상적으로 종료되는 걸 막고 계속해서 프로그램을 자연스럽게 실행되도록 흐름을 유지할 수 있습니다.
    2. 예외 처리가 가능한 것: 문법 오류, 잘못된 데이터 타입 연산, 존재하지 않는 변수 호출 등 작성한 파이썬 코드 수준에서 발생하는 문제들은 try-except로 잡아서 복구할 수 있습니다.
    3. 처리 불가능한 것: 컴퓨터 전원 이슈, 하드웨어 고장, 운영체제 자체의 치명적인 문제처럼 코드 수준을 넘어선 물리적/시스템적 한계는 프로그램 내부 코드만으로는 해결이 불가능합니다.
