# Python

1. 자료형의 특징 : 타입이 동일해야 연산이 가능하다.  ex) 숫자+문자=>불가능
2. 데이터는 저장방식이 데이터에 따라 다르다.
3. 변수 설정은 재사용의 목적. (필요할 때 사용하기 위함)
4. 변수는 메모리 주소값을 저장하기 때문에 a=100을 선언하고 a='string'을 선언해도 오류가 아님. => a라는 이름표가 가리키는 대상이 완전히 교체된 것.
5. 숫자형: int(정수), float(실수) / 문자형: str(문자열) / 논리형: boolean -> 값: true/false/ 컬렉션형: list, tuple, set, dictionary
6. Python의 특징 :  인터프리터: 라인단위 실행 / 동적 타이핑: 타입의 정의가 완료되는 시점(변수의 메모리 공간을 생성하는 시점)
7. Python을 설치하면 => 함수, 내장함수, 기본함수 바로 사용가능.
8. 데이터들은 객체 형식으로 저장된다. / 객체: 데이터의 저장, 기능(함수)들을 포함.
9. 문자열: 순서가 있는 문자들의 집합 / ' '  or " " 로 문자열을 묶어주면 문자열 객체 생성. / 'str' => 문자들 저장, 함수들 포함 / len(문자열 함수): 시퀀스 데이터의 데이터 길이(size)를 구함.
10. 시퀀스 데이터:  데이터들을 시퀀스(순서대로 나열) 형식으로 저장.
11. 시퀀스 타입: str(문자열), list(리스트), tuple(튜플)
12. 개행이란 줄바꿈을 뜻한다.
13. 위치값(index)으로 데이터를 추출한다.
14. 위치 알려주는 메서드(method) find => 위치 데이터가 없으면 -1 값을 반환한다. / 문자열 메서드 중 .index()도 찾는 역할은 똑같지만, 찾는 값이 없을 때  -1 을 반환하는 대신 ValueError 예외(에러)를 발생시킨다는 차이가 있습니다. 따라서 안전하게 "없으면 -1"이라는 분기 처리를 하고 싶을 때는 .find()를 사용하는 것이 좋습니다.
15. 함수(Function)와 메서드(Method) 차이 :

    1. 함수는 특정 객체에 소속되지 않고, 독립적으로 존재하는 코드블록. ex) print(), len(), id() 등은 단독으로 호출해서 사용
    2. 메서드는 특정 객체(클래스) 내부에 종속되어 있는 함수. ex) .find(), .upper(), .append() 등은 문자열이나 리스트라는 객체 뒤에 점(.)을 붙여서 객체의 데이터와 결합되어 동작함.
16. 함수: 필요한 데이터들을 받아서 가공,처리 -> 특정값을 반환.
17. 함수를 사용하는 이유: 프로그램 코드의 가독성 향상 => 오류 해결, 유지보수에 좋다. 불필요한 변수를 삭제할 수 있다, 공통 코드를 찾아서 함수를 만듦.
18. 함수는 기능을 만드는 것 => 데이터가 필요 없을 수 있다, 데이터를 받지 않고 특정 처리를 할 수 있다,  특정값을 반환하지 않을 수도 있다. => 선택적
19. 리스트, 튜플 -> 시퀀스, 순서 유지. index가 있음. 중복값 허용.
20. 리스트: 변수들의 묶음. 변수들은 주소값을 각각 가짐 => 파이썬이 제공하는 type 모두 가능 ex) e=[1, 2, ['Life', 'is']]   => list안에 int, list 모두 가능.
21. 튜플은 요소 값 변경 불가능.

    1. 1개의 요소만을 가질 때는 요소 뒤에 쉼표(,)를 반드시 붙여야 한다. ex) t1=(1,)
    2. 소괄호를 생략해도 무방하다. ex) t2 = 1, 2, 3
    3. 리스트처럼 중첩도 가능하다. ex) t5=('a','b',('ab','cd'))
22. 딕셔너리(k-v): key: 고유값, 식별 가능해야 함. 중복 불가(유니크)/ value: 값(data)
23. 집합(set): 중복 불가, 순서 없음.
24. Java와 비교했을 때 Python 클래스의 특징:

    1. new키워드가 없고 그냥 생성자 함수를 호출하듯 쓴다. ex) my_car = Car()
    2. self 키워드: 자바의 this에 해당하는 역할. 파이썬 클래스 안의 메서드에서는 인스턴스 자기 자신을 가리키는 self를 첫 번째 매개변수로 무조건 명시해 주어야 함.
    3. 생성자 이름: 자바는 클래스 이름과 같은 생성자를 쓰지만, 파이썬은 __init__을 사용한다.
